VisionFix is an Android app that helps make websites easier to use for people with vision disabilities. 
Many websites have cluttered layouts, missing labels, and other accessibility problems that make them hard to navigate. 
Our app tries to fix that by acting like a middle layer between the user and the website.
When a page loads, VisioFix removes distractions like ads and popups, repairs missing labels on buttons and links, 
and creates a simpler **Focus Mode** with just the important content like headings, paragraphs, and links. 
The app also includes **text-to-speech, haptic feedback, voice search, and shake gestures** to make browsing easier and more accessible.
We created this project to show that the web can be made more inclusive without needing to rebuild every website from scratch. 
VisioFix is still a prototype, but it demonstrates a practical way to reduce barriers for users with visual impairments.
